# Site institucional para o segmento jurídico

Projeto de desenvolvimento front-end de um site institucional responsivo para o segmento jurídico, criado com foco em clareza, credibilidade, acessibilidade e desempenho.

## Funcionalidades

- Layout responsivo para celulares, tablets e computadores
- Páginas institucionais, serviços, equipe, conteúdos e contato
- Navegação acessível e componentes reutilizáveis
- Animações e transições sutis
- SEO técnico, metadados e dados estruturados
- Otimização de imagens e desempenho

## Tecnologias

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Radix UI

## Como executar

```bash
npm install
npm run dev
```

Depois, acesse `http://localhost:3000`.

## Verificações

```bash
npm run lint
npm run typecheck
npm run build
```

## Objetivo

O projeto demonstra a construção de uma presença digital institucional completa, transformando requisitos de negócio em uma experiência moderna, consistente e adaptada a diferentes dispositivos.
